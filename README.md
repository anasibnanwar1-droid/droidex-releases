# DROIDEX Releases

This public repository hosts the official signed and notarized DROIDEX macOS downloads and automatic-update metadata.

Download the latest DMG from [Releases](https://github.com/anasibnanwar1-droid/droidex-releases/releases). Choose `arm64` for Apple silicon Macs or `x64` for Intel Macs. Published releases are immutable and include `SHA256SUMS`.

The application source repository is private during the closed-source release period. GitHub's automatic source archives for this repository contain only these public download documents, not the application source. Electron application code shipped in a DMG remains technically inspectable; no secrets or privileged server credentials are included in the client.

For ordinary bugs, use `/bug <description>` inside DROIDEX and retain the shown `BUG-...` and `USR-...` IDs. Do not open public issues containing prompts, project files, logs, tokens, or personal data.
